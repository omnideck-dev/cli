Installations created by earlier versions without their MCP sign-in address now
regain Slack and MCP integrations. `omnideck update` sets or corrects the
address and reports what it did, Desktop startup repairs it automatically, and
`omnideck doctor` warns when it is missing or wrong. Saved data is preserved,
and Desktop's automatic repair keeps the version the installation already runs.
