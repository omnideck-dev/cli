# omnideck CLI v0.11.0-beta.6

This beta prepares local installations for MCP sign-in in compatible omnideck
application builds and fixes Windows container-to-host routing.

## Added

- The CLI supplies the application's local browser address automatically,
  including when a custom port is used. Compatible omnideck builds can use this
  address to complete MCP integration sign-in without manual environment setup.

## Fixed

- Windows containers now use Podman's host-gateway resolution for
  `host.containers.internal`.

## Upgrading

Existing containers are recreated once when their configuration is reconciled
to apply the new settings. Saved data volumes are preserved. Allow running work
to finish before upgrading or reconciling an installation.

This CLI update does not install MCP features into an older application image.
Desktop users receive the CLI bundled with their desktop release; updating a
separately installed CLI does not replace the desktop's bundled copy.

## Limitations

MCP browser sign-in must happen on the computer running omnideck. Signing in
from a browser on another computer is not supported by this local callback
setup. Provider-specific app registration and workspace approval requirements
still apply.
