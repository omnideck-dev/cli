# omnideck CLI v0.11.0-beta.7

This beta makes Windows setup failures easier to diagnose and provides a direct
link to the recovery instructions.

## Fixed

- Windows setup now explains WSL container-controller failures instead of
  reporting a startup timeout, and links to the
  [Windows WSL recovery steps](https://www.omnideck.dev/install.html#windows-wsl-recovery).
  Configured container resource limits remain enabled. omnideck does not change
  WSL settings automatically.

## Upgrading

Download the archive for your operating system and architecture from this
release and replace your separately installed CLI executable. No configuration
migration is required.

Desktop users receive the CLI bundled with their desktop release; updating a
separately installed CLI does not replace the desktop's bundled copy.

## Limitations

This release improves the error message; it does not fix the underlying
Podman/WSL compatibility issue. If setup cannot apply container limits, follow
the linked recovery instructions. Changes to WSL settings affect every Linux
distribution on the same Windows account.
