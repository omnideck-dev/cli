# omnideck CLI v0.11.0-beta.8

This beta adds Apple Developer ID signing and notarization to the standalone
macOS CLI downloads for Apple Silicon and Intel Macs.

## Security

- macOS executables identify omnideck's verified publisher and are checked by
  Apple's notarization service before release. Downloads are published only
  after these checks finish successfully.
- The Go toolchain is updated to 1.26.9 to address standard-library
  vulnerabilities found by the release security checks.

## Upgrading

Download the archive for your operating system and architecture and replace
your separately installed CLI executable. Existing configuration is preserved.
Desktop users receive the CLI bundled with their desktop release; replacing a
standalone CLI does not change that bundled copy.

## Limitations

The standalone macOS executable uses Apple's online notarization ticket lookup;
its first trust check can require an internet connection. Windows downloads
remain unsigned and may show a publisher warning.

The existing Podman/WSL compatibility limitation remains. If Windows setup
cannot apply container limits, follow the
[Windows WSL recovery steps](https://www.omnideck.dev/install.html#windows-wsl-recovery).
